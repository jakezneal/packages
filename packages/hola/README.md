# 👋 Hola

Hola is a front-end CLI tool for bootstrapping and scaffolding front-end components, stories, and tests. It aims to reduce repetitiveness, and improve consistency.

## Installation

```bash
pnpm add --save-dev @jakezneal/hola
```

Or without installation

```bash
pnpm dlx @jakezneal/hola
```

## Commands

```txt
> jiti ./src/index.ts "--help"

👋 Hola (@jakezneal/hola v1.4.0)

USAGE @jakezneal/hola init|make:component|config

COMMANDS

            init    Initialise a new Hola config in the current directory
  make:component    Generate a component from boilerplate                
          config    Output the current Hola config                       

Use @jakezneal/hola <command> --help for more information about a command.
```
